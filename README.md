# Автозапись звонков для HONOR

Android-рекордер для HONOR Magic8 Pro. Версия 0.2. Приложение автоматически записывает обычные входящие и исходящие звонки после настройки разрешений, папки и Shizuku. На HONOR по умолчанию выбран режим Phone State. Настройка, сохранённая ранее, имеет приоритет.

## Обновление

Распакуйте ZIP на телефоне, откройте `HonorCallTester.apk` и нажмите «Обновить». Если устанавливаете через ADB, выполните `adb install -r HonorCallTester.apk`. Сборка подписана тем же сертификатом и использует тот же ID пакета, что и 0.1. Папка записей, доступ к ней и настройки остаются в приложении при установке поверх 0.1.

## Запуск

Для первой настройки запустите [Shizuku](https://shizuku.rikka.app/) через отладку по Wi-Fi, откройте «Автозапись звонков», выдайте запрошенные разрешения и выберите папку для файлов. У обычной Shizuku после перезагрузки нужно снова нажать «Запустить». Приложение напомнит об этом, если включены уведомления и автозапись. Напоминание можно отключить в настройках.

## Архив

- Вкладка «Записи» показывает файлы из выбранной папки и её подпапок, включая записи версии 0.1.
- В новой записи поиск работает по имени, номеру и названию файла. Имя и номер отображаются, если Android передал их приложению. Для старых файлов доступны данные из имени файла и даты изменения.
- Касание записи открывает плеер с перемоткой, отправкой файла и удалением с подтверждением.
- «Сбои» показывает последние 30 ошибок, о которых узнал рекордер. Вызов, о котором Android не сообщил приложению, в этом списке не появится.
- Автоочистка выключена. Её можно включить на 30 или 90 дней. Система запускает проверку примерно раз в сутки. Она проверяет файлы, успешно сохранённые этой версией, и пропускает избранные, старые, сторонние и изменённые файлы.

После обновления проверьте один входящий и один исходящий с заблокированным экраном. Проверьте, что оба файла появляются в архиве и что в них слышны оба голоса.

## Исходный код

Независимая модификация [ShizuCallRecorder](https://github.com/kitsumed/ShizuCallRecorder) 2.0.0, коммит [fc637e2](https://github.com/kitsumed/ShizuCallRecorder/commit/fc637e2c979ef1afe54215104f53606f329a3bbd). Проект распространяется по [GPL v3](LICENSE) с условиями, указанными в файле лицензии.

Для сборки нужны JDK 21, Gradle 9.8.2, Android SDK 37.0 и Build Tools 37.0.0. Из корня репозитория с установленным SDK и заданной переменной `ANDROID_HOME` выполните `gradle :app:assembleRelease`. Для установки собственной сборки подпишите APK своим ключом.
